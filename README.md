Gobble Dash — a turkey escape game: Giblet the turkey runs 1,800m from the farmyard, through the barn and the kitchen, dodging ovens and thrown carving knives while Farmer Joe hunts him down, to slip through the forest gate before becoming Thanksgiving dinner.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step, no network request: jump with Space, slide with S, dash with Shift, drift with A/D, pause with P, mute with M.
